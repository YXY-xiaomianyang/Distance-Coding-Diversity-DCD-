We have provided Python, Matlab and IDL code to calculate the DCD of an image. 
DCD.ipynb is the Python code of DCD, DCD.m is the Matlab code of DCD, and dcd.pro is the IDL code of DCD.
The DCD_update.jpynb and DCD_update.py files now support configurable pattern selection for DCD computation. Although averaging results from multiple patterns enhances feature sensitivity, it increases processing time. Users may select either individual patterns or pattern combinations based on their specific requirements.
